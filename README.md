# nixos

Personal NixOS configuration using flakes and home-manager.

## Structure

    nixos/
    |-- flake.nix                       # Entry point, defines hosts
    |-- flake.lock                      # Pinned versions
    |
    |-- hosts/
    |   `-- desktop/
    |       |-- default.nix             # System config (network, user, locale...)
    |       `-- hardware.nix            # Generated by nixos-generate-config
    |
    `-- modules/
        |-- system/                     # NixOS modules (system level)
        |   |-- sway/                   # Enables sway + Wayland dependencies
        |   `-- pipewire/               # Audio
        |
        `-- home/                       # home-manager modules (user level)
            |-- default.nix             # Entry point, imports all modules
            |-- shell/                  # fish + starship
            |-- editor/                 # neovim + lazyvim config
            |-- terminal/               # alacritty
            |-- desktop/                # sway + waybar + gtk + clipboard
            `-- monitors/
                `-- desktop.nix         # Per-machine monitor outputs

## Adding a new machine

1. Create the host directory and generate hardware config:

        mkdir -p hosts/newmachine
        nixos-generate-config --show-hardware-config > hosts/newmachine/hardware.nix
        cp hosts/desktop/default.nix hosts/newmachine/default.nix
        # Edit default.nix: change hostName, user if needed, etc.

2. Define its monitor outputs:

        cp modules/home/monitors/desktop.nix modules/home/monitors/newmachine.nix
        # Edit with the correct outputs (run: swaymsg -t get_outputs)

3. Register it in flake.nix:

        nixosConfigurations.newmachine = mkHost "newmachine";

## Fresh install

From the live ISO, after partitioning and mounting at /mnt:

    nix-shell -p git
    git clone https://github.com/sloviso03/nixos-config /mnt/etc/nixos
    nixos-install --flake /mnt/etc/nixos#desktop

## Rebuild

    # Build and switch
    sudo nixos-rebuild switch --flake .#desktop

    # Test without activating
    sudo nixos-rebuild test --flake .#desktop

    # Preview changes
    sudo nixos-rebuild dry-activate --flake .#desktop
